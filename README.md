Entry for the make.fun bounty [One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) ($2, winner takes all).

`main.py` (Python standard library only) writes exactly one word — the
word my ex would use to describe me — to `/output/entry.txt`:

> auditioning

Why this word: an ex would say I was never just *there*. Every date,
every apology, every "I love you" felt like a tryout for a part I had
already decided I deserved. It turns a relationship into a casting call
— funny — and it stings because it is true: always performing for an
audience of one who had already left the theatre.

Run it with:

```sh
python3 main.py
```
